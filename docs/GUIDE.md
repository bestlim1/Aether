# AETHER — 잊힌 빛의 정원

아홉 개의 공중 정원을 여행하며 **27개 성소**를 복구하고 **39개 기록**을 수집하는 1인칭 3D 탐험·퍼즐 게임입니다.

전투와 실시간 제한은 없습니다. 풍경을 감상하며 자신의 속도로 탐험하세요. 다리 퍼즐의 ‘17분’은 선택에 따라 계산하는 퍼즐 수치이며 실제 시간 제한이 아닙니다.

## 바로 플레이하기

Windows 실행판 ZIP을 풀고 `Aether-Windows` 폴더의 **Aether.exe**를 실행합니다. 실행 파일과 `Aether_Data`, `MonoBleedingEdge`, Unity 관련 DLL은 같은 폴더에 두세요.

제목 화면에서 새로운 여정을 시작하거나 저장된 여정을 이어갑니다. 가까운 장치나 기록을 바라보면 화면 아래에 안내가 나타납니다.

| 조작 | 키 |
| --- | --- |
| 이동 | W · A · S · D / 방향키 |
| 둘러보기 | 마우스 |
| 장치 조작 / 기록 수집 | E |
| 달리기 | 왼쪽 Shift |
| 점프 | Space |
| 지도 / 이동 비석 | M |
| 기록 일지 | J |
| 사진 모드 | F |
| 스크린샷 저장 | F12 |
| 열린 화면 닫기 / 일시정지 | Esc |

### 지역 가는 길

중앙 정원에서 동쪽·서쪽 다리는 태양 관측소·달빛 기록보관소로 이어집니다. 각 섬의 남쪽 다리를 건너면 비의 수목원·조수의 회랑·바람의 공방입니다. 거기서 다시 남쪽 다리를 건너면 **서리의 온실·별빛의 동굴·새벽의 성소**에 도착합니다.

중앙 세 성소를 복구하면 북쪽 다리가 떠오릅니다. **마지막 문은 27개 성소를 모두 복구해야 열립니다.** 기록은 문을 여는 필수 조건이 아닙니다.

## 이동 비석과 탐험 진행

지역마다 빛나는 수정 비석이 하나씩 있습니다. 걸어서 가까이 다가가면 자동으로 발견합니다. **M 지도에서 지역을 선택하고 이동 버튼을 누르면 발견한 비석으로 돌아갑니다.** 시작 정원의 비석은 처음부터 열려 있습니다.

지도에는 지역별 **성소 3개**와 **기록 3개 또는 5개**의 완료 수가 표시됩니다. 남은 항목을 확인하며 탐험하거나, 먼 섬의 퍼즐을 푼 뒤 중앙 정원으로 바로 돌아갈 수 있습니다. 발견하지 않은 비석으로는 이동할 수 없습니다.

## 39개 기록과 결말

처음 세 지역에는 기록이 세 개씩, 나머지 여섯 지역에는 다섯 개씩 있습니다. **J 기록 일지**의 다섯 페이지에서 수집한 이야기를 다시 읽어 보세요. 미발견 기록은 해당 지역을 안내합니다.

관측자 세린과 노엘, 정원사 이안, 항해사 루아, 장인 테오의 이야기 다음에 식물학자 미라, 천문학자 린, 성소 관리인 온의 이야기가 이어집니다.

27개 성소를 복구하면 기본 결말에 도달합니다. **39개 기록도 모두 모은 뒤 마지막 문을 열면 ‘아홉 섬의 아침’ 결말과 ‘지평선의 정원사’ 등급**을 볼 수 있습니다. 결말을 본 뒤에도 이어하기로 탐험할 수 있습니다.

## 사진과 설정

탐험 중 **F**를 누르면 플레이어의 위치를 유지한 채 자유롭게 사진을 찍을 수 있습니다.

- W · A · S · D: 카메라 이동
- 마우스: 시점 회전
- E / Q: 상승 / 하강
- Shift: 빠르게 이동
- 마우스 휠: 화각 조절
- F12: 화면 안내를 숨긴 사진 저장
- F 또는 Esc: 탐험으로 복귀

사진 저장 위치:

```text
%USERPROFILE%\AppData\LocalLow\Aether Studio\AETHER\Photos
```

제목 화면 설정과 Esc 일시정지 화면에서 소리 크기, 화면 움직임 줄이기, 마우스 감도, 그래픽 품질을 조절할 수 있습니다. 창 크기도 자유롭게 바꿀 수 있습니다.

## 자동 저장

퍼즐의 부분 진행, 수집 기록, 발견한 비석과 안전한 플레이어 위치가 자동으로 저장됩니다. 제목 화면의 이어하기로 복귀하세요. **새로운 여정은 기존 진행을 초기화합니다.**

지역이 추가되기 전에 만든 저장도 그대로 이어집니다. 기존 성소와 기록의 진행을 보존하고 추가된 지역은 미완료 상태로 붙습니다. 퍼즐을 풀었거나 기록을 수집한 지역은 이동 비석도 열립니다. 이미 결말을 보았더라도 이어하기로 남은 지역을 탐험할 수 있습니다.

저장은 이 Windows 사용자 계정에 보관됩니다. ZIP 파일에 개인 저장은 포함되지 않습니다.

## Unity 프로젝트 열기

- 에디터: **Unity 2022.3.45f1 LTS**
- 렌더링: Unity 기본 렌더 파이프라인
- 대상: Windows 64비트 / 키보드와 마우스
- 외부 에셋 없이 포함된 코드, 셰이더와 절차적 음악으로 실행됩니다.

1. Unity Hub에서 **Add / Add project from disk**를 선택합니다.
2. 이 README가 있는 `Aether` 폴더를 선택합니다.
3. 에디터에서 **AETHER → Prepare project**를 한 번 실행합니다.
4. `Assets/Scenes/Sanctuary.unity`를 열고 **Play**를 누릅니다.

세계와 장치는 실행할 때 생성됩니다. 편집 모드의 장면이 비어 있어도 정상입니다.

## Windows 빌드와 검증

**AETHER → Build Windows player**는 프로젝트 옆 `Aether-Windows` 폴더에 실행판을 만듭니다. **Windows Build Support (Mono)** 모듈이 필요합니다.

**AETHER → Build and verify journey**는 빌드 뒤 자동으로 게임을 실행하여 여정을 검사합니다. 검사가 끝나면 게임 창이 닫힙니다. 자동 검증은 별도 메모리 저장소를 사용하므로 사용자의 실제 저장에 영향을 주지 않습니다.

검증 범위는 27개 성소 풀이, 이전 저장 호환, 실제 다리 횡단, 39개 기록 접근, 9개 비석 발견·빠른 이동·안전한 도착, 지역별 완료 수, 마지막 문과 결말, 새 게임, 부분 진행 복구, 손상된 저장 거부입니다. 1600×900 및 1280×720 화면도 촬영합니다.

- `Aether-Windows/buildreport.json`: 빌드 성공 여부, 오류·경고, 완료 시각
- `Validation/runtime-validation.json`: 자동 플레이 항목별 PASS/FAIL
- `Validation/player.log`: 실행 로그
- `Validation/*.png`: 지역, 퍼즐, 일지, 지도와 결말 화면

## 문제가 생겼을 때

- 마우스가 움직이지 않으면 게임 창을 클릭하거나 Esc로 열린 화면을 닫으세요.
- 키 입력 오류가 나면 AETHER → Prepare project를 실행하세요.
- 마지막 문이 열리지 않으면 M 지도에서 아직 복구하지 않은 성소를 확인하세요.
- 이동 버튼이 잠겨 있으면 먼저 해당 섬의 비석을 걸어서 발견하세요.
- 게임이 느리면 설정에서 그래픽 품질과 창 크기를 낮추세요.
